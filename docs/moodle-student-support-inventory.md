# Moodle 4.5 学生機能・プラグイン棚卸し

本書は、本番に有効な Moodle 4.5 LTS の学生向け機能を公開する前に、
Moodle 管理者と確認するための記録です。学生の氏名、トークン、提出物、
またはコース本文は記録しません。

## 管理者が記入する項目

- Moodle リリース番号と適用済みセキュリティ更新
- 専用外部サービスに許可した外部関数一覧
- 有効な活動、コース形式、提出プラグイン、質問タイプ、ブロック、認証連携
- 学生ロールで可能な操作（閲覧、保存、提出、受験、投稿、参加）
- 各種別を検証できる匿名化済みの代表コース・代表アカウント

## 対応判定

| 提供方式 | 使用条件 | 公開前の確認 |
| --- | --- | --- |
| `native` | 公式 Web Service の型付き DTO だけで学生操作を完結できる | 読み取り・書込み・権限不足・期限切れ |
| `adapter` | プラグイン固有の構造を `local_nextmoodle` が型付き契約で返す | 入出力スキーマ、権限、既存データとの互換性 |
| `runtime` | SCORM / H5P など Moodle 実行環境が必要 | 単回チケット、ユーザー／活動束縛、フレーム制限 |
| `unavailable` | まだ安全な実装または契約がない | 学生には公開せず、接続診断だけで種別を通知 |

各プラグイン更新後は、本書と接続診断のカタログを更新し、代表コースで
回帰試験を通してから公開します。
